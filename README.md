# 泰拉瑞亚模组简体中文汉化集合

个人制作的泰拉瑞亚（tModLoader）模组简体中文汉化集合。本仓库按模组分目录存放翻译文件，方便归档、查阅和后续维护。

## 内容说明

每个文件夹对应一个模组，文件夹内为 `zh-Hans_Mods.模组名.hjson` 格式的翻译文件。

| 模组 | 汉化状态 | 创意工坊链接 |
| --- | --- | --- |
| Progression Journal | 持续更新 | https://steamcommunity.com/sharedfiles/filedetails/?id=3824019358 |

## 使用方法

### 方式一：订阅创意工坊汉化补丁（推荐）

前往上方表格中的创意工坊链接订阅对应的汉化补丁，并同时订阅原模组，在 tModLoader 中同时启用即可。

### 方式二：手动放入原模组

如果你有原模组源码，可将对应文件夹内的 `zh-Hans_Mods.模组名.hjson` 放入原模组的 `Localization` 文件夹，构建并重新加载原模组。
